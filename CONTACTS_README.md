# Система управления контактами и Push-уведомлений

## Описание

Добавлена полноценная система управления контактами с возможностью отправки push-уведомлений. Система включает:

### Основные функции:
- ✅ **Управление контактами**: Добавление, редактирование, удаление
- ✅ **Поиск**: Быстрый поиск по имени, телефону или виду деятельности  
- ✅ **Множественный выбор**: Выбор нескольких контактов для массовой отправки
- ✅ **Push-уведомления**: Отправка персонализированных сообщений

### Структура контакта:
- **Телефон** - номер телефона контакта
- **Имя** - полное имя контакта
- **Вид деятельности** - профессия или должность
- **Firebase Token** - токен для push-уведомлений (опционально)

## Файлы системы

### Новые файлы:
- `contacts.php` - API для работы с контактами (CRUD операции)
- `send_to_contacts.php` - отправка push-уведомлений выбранным контактам
- `contacts.js` - JavaScript логика управления контактами
- `sample_data.php` - добавление примеров контактов для тестирования
- `contacts.db` - база данных SQLite (создается автоматически)

### Обновленные файлы:
- `index.html` - добавлен современный интерфейс с тремя вкладками
- `app.js` - улучшена обработка уведомлений

## Установка и настройка

### 1. Требования:
- PHP 7.0+ с поддержкой PDO и SQLite
- Web-сервер (Apache/Nginx)
- Настроенный Firebase для push-уведомлений

### 2. Первоначальная настройка:

1. Убедитесь, что все файлы загружены на сервер
2. Проверьте права доступа к папке для создания файла `contacts.db`
3. Запустите `sample_data.php` для добавления примеров контактов:
   ```
   http://ваш-домен.com/sample_data.php
   ```

### 3. Настройка Firebase:
- Убедитесь, что Firebase API ключ настроен в `send_to_contacts.php`
- Токены пользователей будут сохраняться автоматически при регистрации

## Использование

### Интерфейс состоит из 3 вкладок:

#### 1. **Уведомления**
- Отправка тестового push-уведомления
- Проверка работы Firebase

#### 2. **Контакты** 
- Добавление новых контактов
- Просмотр всех контактов
- Поиск по имени, телефону или деятельности
- Редактирование и удаление контактов

#### 3. **Массовая отправка**
- Выбор нескольких контактов (чекбоксы)
- Создание персонализированного сообщения
- Отправка push-уведомлений выбранным контактам
- Просмотр результатов отправки

### Поиск контактов:
- Поиск работает в реальном времени
- Ищет по всем полям: имя, телефон, вид деятельности
- Результаты обновляются автоматически при вводе

### Массовая отправка:
1. Выберите контакты (кликните по карточке или чекбоксу)
2. Заполните форму сообщения (заголовок и текст обязательны)
3. Опционально добавьте иконку и ссылку
4. Нажмите "Отправить выбранным контактам"
5. Просмотрите детальные результаты отправки

## API Endpoints

### Контакты (`contacts.php`):
- `GET /contacts.php` - получить все контакты
- `GET /contacts.php?search=текст` - поиск контактов
- `GET /contacts.php?id=123` - получить контакт по ID
- `POST /contacts.php` - добавить новый контакт
- `PUT /contacts.php` - обновить контакт
- `DELETE /contacts.php` - удалить контакт

### Отправка сообщений (`send_to_contacts.php`):
- `POST /send_to_contacts.php` - отправить сообщение выбранным контактам

## Структура базы данных

```sql
CREATE TABLE contacts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    phone VARCHAR(20) NOT NULL,
    name VARCHAR(100) NOT NULL,
    activity VARCHAR(200) NOT NULL,
    token VARCHAR(500),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## Безопасность

- Все пользовательские данные экранируются от XSS
- SQL-запросы используют подготовленные выражения
- Валидация данных на стороне клиента и сервера
- Обработка ошибок без раскрытия системной информации
